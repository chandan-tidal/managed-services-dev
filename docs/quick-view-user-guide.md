# User Guide: Quick View Popup on Product Listing Page (PLP)

## Overview
The **Quick View** feature allows customers to view product details in a popup without leaving the Product Listing Page.  
The popup includes:
- Product images  
- Variant options  
- Price  
- **Add to Cart** button  

---

## How to Use

### 1. Access the Quick View
- On the Product Listing Page, hover over or click the **Quick View** button on a product card.  
- The button’s position (e.g., **top-left**, **bottom-right**) depends on your theme settings.  

### 2. View Product Details
The popup displays:
- A slider with product images  
- A variant picker for selecting options (e.g., size, color)  
- The product price (including any discounts)  
- An **Add to Cart** button  

### 3. Close the Popup
- Click the **close (X)** button, or  
- Click outside the popup to return to the PLP  

---

## Customization Options

### Enable/Disable Quick View
- Go to **Shopify Theme Editor > Sections > Collection Product Grid**  
- Check/uncheck **Enable Quick View** to show/hide the button  

### Button Placement
Options:  
- Top Left  
- Top Right  
- Bottom Left  
- Bottom Right  
- Center  

### Typography
- Font size: `12px`, `14px`, `16px`, `18px`, `20px`  
- Font weight: **Regular**, **Medium**, **Semibold**, **Bold**  
- Text case: **Default** or **Uppercase**  

### Popup Element Order
Set the order of elements (1st to 4th position):  
1. Images  
2. Price  
3. Variant Picker  
4. Add to Cart  

*Example:* Set **Images** to 1st, **Price** to 2nd, **Variant Picker** to 3rd, and **Add to Cart** to 4th.  

---

## Troubleshooting

- **Button Not Visible** → Ensure **Enable Quick View** is checked in the theme settings.  
- **Popup Content Missing** → Verify the product has images, variants, and a price set in Shopify.  
- **Responsive Issues** → Test on different devices; contact support if layout issues persist.
