User Guide: Variant Color Filtering on Product Detail Page (PDP)
Overview
The Variant Color Filtering feature on the Product Detail Page allows customers to view only the images associated with the selected color variant, making it easier to visualize the product in their chosen color.
How to Use

Select a Color:
On the Product Detail Page, locate the variant picker (usually labeled "Color").
Choose a color (e.g., Red, Blue, White) from the variant pickar.


View Filtered Images:
The media gallery automatically updates to display only images for the selected color.
Other images (e.g., for different colors) are hidden.


Navigate the Gallery:
Use the slider arrows or thumbnails  to view all images for the selected color.
The gallery updates instantly without reloading the page.



Troubleshooting

Images Not Filtering: Ensure product images have correct alt tags matching the color variants in Shopify admin.
Gallery Not Updating: Verify JavaScript is enabled in the browser; contact support if issues persist.
Responsive Issues: Test on different devices; ensure theme settings are configured correctly.
